## 三、作業問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
在 Python 中，加上引號的 `"4"` 是字串（`str`）型別，電腦只會把它當成一般文字符號，而不是可以做數學運算的數值。在本題的計算中，應付總額 `total_amount` 是浮點數（`float`），如果直接拿浮點數去除以字串（例如 `1220.0 / "4"`），程式會因為資料型別不相容而發生 `TypeError` 錯誤並中斷執行。因此必須先用 `int(people)` 把 `"4"` 轉成整數（`int`）型別的 `4`，才能順利做除法算出每人分攤費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
* **應付總額會變成：** **1,210 元**。
* **算式說明：**
  1. 先扣折價券後的剩餘餐費：$1,200 - 100 = 1,100$ 元
  2. 依剩餘餐費計算 10% 服務費：$1,100 \times 0.10 = 110$ 元
  3. 應付總額：$1,100 + 110 = 1,210$ 元
* **與題目規定不同的原因：**
  題目規定服務費必須以「原始餐費（1,200 元）」計算，所以服務費是 $1,200 \times 0.10 = 120$ 元，加上服務費後再扣除 100 元折價券，總額為 $1,200 + 120 - 100 = 1,220$ 元。如果改成先扣掉 100 元折價券再算服務費，被折抵掉的那 100 元就沒有被算到 10% 服務費（少算了 $100 \times 0.10 = 10$ 元），因此應付總額會比題目規定的 1,220 元少 10 元。
